# YouTube to MP3 Desktop (Rust + Tauri для Windows)

Монолитное десктопное приложение для Windows на базе **Rust** и **Tauri 2**.  
Все компоненты (`yt-dlp.exe`, `ffmpeg.exe`, веб-интерфейс и Rust-ядро) вшиты в единый портативный исполняемый файл `.exe`.

## Особенности

- **Единый автономный `.exe`**: скачал и сразу запустил, не требует прав администратора или установки.
- **Вшитые бинарники**: `yt-dlp.exe` и `ffmpeg.exe` запекаются в бинарник через `include_bytes!` и автоматически извлекаются во временную память при старте.
- **Нативный выбор папки**: сохранение в любую удобную папку через стандартный Проводник Windows (`rfd`). По умолчанию используется системная папка «Музыка» (`%USERPROFILE%\Music`).
- **Живой прогресс**: перехват вывода `yt-dlp` и передача реального процента, скорости и оставшегося времени (ETA) через события Tauri IPC.
- **Кнопка «Показать в Проводнике»**: моментальное открытие папки с выделенным сохраненным MP3 файлом.
- **Выбор качества аудио**: 128 kbps, 192 kbps (оптимальный баланс) или 320 kbps (HQ).

## Структура проекта

```
yt-to-mp3-desktop/
├── src-tauri/
│   ├── bin/                    # Вшиваемые бинарники
│   │   ├── fetch_bins.sh       # Скрипт загрузки бинарников
│   │   ├── yt-dlp.exe          # Windows yt-dlp
│   │   └── ffmpeg.exe          # Windows FFmpeg
│   ├── icons/                  # Иконки приложения (ico, png)
│   ├── src/
│   │   ├── bin_manager.rs      # Извлечение бинарников из памяти в %TEMP%
│   │   ├── downloader.rs       # Управление процессом скачивания и стриминг прогресса
│   │   └── main.rs             # Регистрация команд Tauri IPC
│   ├── Cargo.toml
│   └── tauri.conf.json
├── ui/                         # Фронтенд (HTML, CSS, JS)
│   ├── index.html
│   ├── style.css
│   └── app.js
├── .github/workflows/          # Автоматическая облачная сборка под Windows
│   └── build-windows.yml
└── package.json
```

## Сборка готового `.exe` под Windows

### Вариант 1: Сборка в облаке GitHub Actions (Рекомендуется)
1. Загрузите репозиторий на GitHub (`git push`).
2. Перейдите во вкладку **Actions** в репозитории.
3. Запустите workflow **Build Windows Single EXE** (или сделайте коммит в `main`).
4. По завершении сборки скачайте готовый архив с файлом `YouTube to MP3.exe` из раздела **Artifacts**.

### Вариант 2: Локальная сборка на компьютере с Windows
1. Установите [Rust](https://rustup.rs/) и [Node.js](https://nodejs.org/).
2. Откройте терминал в папке проекта:
   ```cmd
   npm install
   npm run tauri build
   ```
3. Готовый бинарник будет находиться по пути:
   `src-tauri/target/release/YouTube to MP3.exe`
